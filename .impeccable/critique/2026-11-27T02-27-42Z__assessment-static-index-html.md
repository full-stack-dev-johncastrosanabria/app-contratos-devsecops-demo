#### Anti-Patterns Verdict

Authored for this product, not interchangeable with other products in its category. Several things only make sense for REN-001 across v1/v2/v3: the 8-station corridor with DevSec and CloudOps lines meeting at a "Núcleo determinista" hub, with per-version state pips that use glyphs as well as color; the verdict strip that names the deciding test ("Prueba «cancelado no genera aviso»: fallida"); xUnit rows in each card with the REN-001-tagged test highlighted, the SHA-256 file count and the test source line; the copyable WIQL fingerprint "devsecops-fp-…"; and a Boards confirmation that explains AB#1 idempotent upsert. The first viewport meets the contract (navy masthead with live :5080 state, compact command deck, corridor, matrix heading at y≈880). The build departs from the contract in two places. First, the THESIS rejects "tarjetas anidadas", yet each matrix card holds 5–7 bordered or tinted inner boxes: next-step, "Fuera de REN-001", "Conforme", dashed stage rows, the verified-chip strip and the governance confirm box. Second, the generic SaaS chip and pill vocabulary (badges, outlined ghost buttons) carries much of the card body, so below the corridor the matrix reads less like a "libro mayor" and more like a standard dashboard card grid. The brand mark's cyan halo is sanctioned by PRODUCT.md and is not flagged.

#### Overall Impression

The opening is the high point. Within seconds the verdict strip gives a confident answer (v1 ✓ Verificado / v2 × Incumplido / v3 ? Evidencia insuficiente), each with its deciding test, and the provenance line \"corridas en caché (0 tokens)\" reassures about cost. The corridor is a pleasant middle: the transit map and the inspector's \"Pregunta de gobierno → Respuesta en v2\" feel authoritative. The low point is the matrix. Long cards, monospace test lists, agent prose and SecOps counts that seem to contradict \"Verificado\" (v1: 1 alta) introduce doubt right after the reassurance, and a sharp viewer may notice that all three cards show the same commit. The high-stakes moment is handled well: the Boards confirmation explains idempotency, focus defaults to Cancelar, discarding warns that it is permanent, and a 5-second Deshacer follows. Running is mildly anxious. There is an indeterminate bar and an elapsed clock but no estimate, the hub clock scrolls off-screen, and only Esc×2 or the red button stops a paid run. The ending is strong: the navy matrix-close bar (\"v1 queda certificada… Siguiente paso: decidir las 2 acciones\" plus jump buttons) delivers the closing summary and next action that peak-end calls for.

#### What's Working

- The verdict comes first and is backed by evidence. The verdict strip in the first viewport (desktop and mobile) answers Principle 2 by naming the deciding test outcome for each delivery. Each card then shows the actual xUnit rows, with the REN-001-tagged CanceladoNoGeneraAviso highlighted (red row "Fallida" in v2, absent in v3), plus the source line and SHA-256 file count. Agent narrative sits collapsed behind an explicit "Contexto del agente: no decide el dictamen".
- The HITL governance flow is careful. "Descartar" with an empty note gives an inline error, sets aria-invalid and moves focus to the field. "Aprobar" opens a confirmation that explains the idempotent AB#1 upsert with the fingerprint. Focus lands on Cancelar (keyboard-verified with a visible 3px ring). Esc inside the box cancels, a 5-second Deshacer follows confirmation, and on failure the note is preserved with a Reintentar button.
- Keyboard and focus handling is careful throughout. Esc closes layers in order. Focus returns to the station you stepped to, or to the card row that opened the inspector. Opening from the matrix docks a bottom sheet that keeps the source row visible and highlighted. Tab order is logical with no positive tabindex. The skip link works. The corridor reflows to two lines of four on a 390px screen with no horizontal overflow and touch targets of at least 44px. JS animations respect reduced-motion.
