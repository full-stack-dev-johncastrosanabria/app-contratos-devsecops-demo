#### Anti-Patterns Verdict

This was built for this product, not reused from a generic template. The 8-station transit corridor has a DevSec line, a CloudOps line and a "Núcleo determinista" hub, and each station shows per-version pips. The verdict strip names the test that decided each verdict (CanceladoNoGeneraAviso: aprobada/fallida, Ninguna prueba vinculada). There is a WIQL fingerprint copy chip, and HITL governance uses a confirm step whose default is Cancelar. Cards show cache-vs-live provenance and the agent engine's token cost appears in the button labels. None of this would carry over to another product unchanged. The generic layer is the card-and-badge shell: rounded cards, pill buttons, tinted alert boxes. That shell also goes against the direction contract. The contract rejects nested cards, but the page has three levels of nesting: matrix card > tinted governance panel > tinted confirm box, and dashed shared band > tinted stage boxes. The contract's "FIRST VIEWPORT ... arranque inmediato de la Matriz" is also missed: at 1440x900 the matrix heading sits at y=925 and the first card at y=1238. The verdict strip covers the 5-second read in the meantime.

#### Overall Impression

It opens strong. The navy institutional masthead and the verdict strip deliver the answer in about 5 seconds ('2 de 3 entregas con brecha · 2 acciones esperan revisión humana'), with the deciding test named, and that is the peak of confidence. The first dip comes in the matrix. v1's green 'Verificado' sits next to a red SecOps box, and every card has a yellow 'Evidencia insuficiente' stage 5, so confidence turns into doubt ('is v1 actually certified?'). A second dip comes when the user opens station 4 to understand v2's failure and finds '4 pruebas ejecutadas en TRX' for both the passing and the failing delivery, which is an anticlimax. On mobile, or at presentation zoom, the long scroll to a v3 card on its own makes the comparison feel like a chore. The high-stakes moment, approving or discarding into Azure Boards, is handled reassuringly: the fingerprint is visible, there is an explicit confirm, Cancelar has focus by default, the note is required to discard and is kept if submission fails. That is the best emotional design on the page. The ending is weak for peak-end: after the decision the page trails off into collapsed agent disclosures and a footer, with no closing summary or next step. During a live paid run the presenter sees a spinner, an animated rail and '2 de 3', but no elapsed time, which is uncomfortable in front of an audience.

#### What's Working

- The verdict strip answers the product's core question within 5 seconds: '2 de 3 entregas con brecha · 2 acciones esperan revisión humana · corridas en caché (0 tokens)'. Each chip names the test that decided the verdict and the high-severity SecOps count, and jumps to its card. This meets Principle 2 directly and stays three across even at 1152 px.
- The high-stakes HITL step is careful. Aprobar or Descartar opens an inline confirmation that states the parent story and the WIQL fingerprint. Focus starts on Cancelar, so a stray Enter writes nothing. Esc cancels. Discard requires a note and shows the error next to the field with focus moved there. A failed submit keeps the note and offers Reintentar.
- Keyboard and assistive-technology work is above average. There is a skip link, a 3px focus ring that switches to cyan on navy, and Esc peels layers with focus restored to where the user started. Station buttons carry screen-reader text per version ('v1 verificado, v2 incumplido, v3 evidencia insuficiente'). Pips use shape as well as colour. Forced-colors and reduced-motion are supported. Every target is at least 44 px at 390 px, there is no horizontal overflow, and the contrast scan found 0 text failures in the default state.
